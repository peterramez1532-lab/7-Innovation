# 7innovation — Startup AI Research

Single-file landing page for 7innovation. The website is contained in `index.html` with all CSS and JavaScript inline, so there are no project folders to upload.

## Deploy on Vercel
- Framework preset: Other
- Build command: leave empty
- Output directory: `.` (or leave default if deploying as static HTML)
- Install command: leave empty

Upload `index.html` to the root of your GitHub repository.
